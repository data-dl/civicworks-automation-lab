For hiring managers and recruiters

What this portfolio shows

Most data problems are not hard queries - they are a wrong number that gets published, a job that "succeeds" with nothing in it, or two systems that quietly disagree. These eight pipelines show how I stop that: every input is checked against rules, people approve what a rule cannot decide, outputs are verified before anyone sees them, and every run leaves evidence. All of it is tested on every change.

Found by experimenting

Testing the pipelines against their own experiments found real bugs

A badge with an unknown type vanished silently from a public release because of an inner join - it now blocks the release and names the badge. A person's name that drifted under the same member id passed unreported - it is now noted for review. A report step crashed when a quarter was never approved. Each is fixed, with a test that keeps it fixed.
