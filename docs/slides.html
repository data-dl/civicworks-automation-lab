1 / 6 · CivicWorks Automation Lab

Reliable automation, from messy inputs to verified outputs.

Eight data pipelines on invented data. Each catches planted problems, stops where a person must decide, and leaves evidence of everything it did.

2 / 6 · The problem

Published data multiplies every mistake.

A wrong record in a report, a directory or a public file reaches everyone who uses it. Exports fail quietly. Two systems disagree. A rerun duplicates work. These pipelines are built so none of that happens silently.

3 / 6 · What I built

Eight pipelines, one standard.

Atlas License DirectoryA monthly printed directory that is checked, frozen, printed, verified and published - and can be rolled back.
OpenBadge Registry PublisherA public data file that only goes live after it has been fetched back and proven identical.
Regional Programs AnalyticsQuarterly Excel reports that refuse approval while the data is incomplete, and freeze once approved.
LedgerGuard Data QualityDaily export checks that never mistake an empty file for success, with archives you can safely restore.
SafeSite Compliance CycleA quarterly safety-return cycle - reminders, checks, escalations and two Word reports - with nothing sent and no final overwritten.
MasterRecord StewardMaster records from three disagreeing sources - justified changes approved, the rest held for a person, nothing else touched.
ReconcileHubMonthly access-roster reconciliation that suggests near-matches and never merges two people on a guess.
OpsPilot Control CenterOne control room over the other pipelines - planned, checkpointed, approved by people, and unable to exceed its contracts.
4 / 6 · How they work

Check, decide, release, keep evidence.

Check before anything is used, and name the problem
The computer never guesses about what needs judgment
Nothing good is ever overwritten
Running it twice is safe
Fingerprints prove what happened
Release all at once, or not at all
5 / 6 · Evidence

106 tests, two operating systems, every change.

GitHub Actions installs all eight projects on fresh Ubuntu and Windows machines and runs every test and every demo after each push. Each run writes a manifest of input and output fingerprints. Every video is replayed from a real run.
