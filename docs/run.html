Try it

Run the pipelines yourself

Everything runs locally with Python 3.11 or newer. No accounts, no network, no real data. Each demo generates its own invented data from a fixed seed, so you see exactly what the videos show.

One command

With Python 3.11 or newer installed:

git clone https://github.com/data-dl/civicworks-automation-lab
cd civicworks-automation-lab
python start.py

It creates a private environment in .venv, installs the eight pipelines and the Lab, checks that every demo runs, and opens the Lab in your browser. Run it again any time - it skips what is already done. On Windows you can also double-click Start CivicWorks Lab.cmd.

Or step by step

git clone https://github.com/data-dl/civicworks-automation-lab
cd civicworks-automation-lab
python -m venv .venv
.venv/Scripts/activate            # macOS/Linux: source .venv/bin/activate
pip install -e "./atlas-license-directory[dev]" -e "./openbadge-registry-publisher[dev]" -e "./regional-programs-analytics[dev]" -e "./ledgerguard-data-quality[dev]" -e "./safesite-compliance-cycle[dev]" -e "./masterrecord-steward[dev]" -e "./reconcilehub[dev]" -e "./opspilot-control-center[dev]" -e ./lab

The CivicWorks Lab: run it one scene at a time

The Lab is a small local web app. Pick a pipeline and it runs the real demo one scene at a time: before each scene it explains what is about to happen and asks you to predict the result; after it, it shows the output and the exact rows and cells that changed. Between scenes you can change the data yourself - edit an input file or run SQL - and watch the pipeline react. Each pipeline also has one-click experiments, safeguard switches, a SQL console with example questions, and the concepts and glossary. A private My prep area for interview practice appears only on the author's own computer.

python -m civicworks_lab          # opens http://127.0.0.1:8870

Step mode without the Lab

Any demo pauses before each scene if CIVICWORKS_STEP=1 is set; press Enter to continue.

CIVICWORKS_STEP=1 python -m atlas demo --out build/step

Tests

cd atlas-license-directory && python -m pytest
