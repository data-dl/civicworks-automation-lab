A story to ask about

An experiment caught a record that vanished silently

Situation. The badge registry publishes a public JSON file only after every record passes validation, including 'every badge type must be known'.

Problem. I built experiments that change the real input data. Giving one badge an unknown type should have blocked the release - instead it went out one badge short, with no finding. The extract query used an inner join to the badge-type table, so the bad badge disappeared before validation ever saw it.

What I did. I changed the extract to LEFT JOINs so a record with a missing type or learner reaches validation, added a rule for unknown learners, and wrote a test that plants the bad type the way a bulk load would - outside the app's foreign-key checks.

Result. The release now blocks and names the badge. The same experiments found two more gaps - a name drift under the same id that passed unreported, and a report step that crashed when a quarter was never approved - each fixed with a test.
